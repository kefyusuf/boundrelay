# D-001 — Project Positioning

- **Status:** Accepted
- **Date:** 2026-09-02

## Decision

The project will teach how to select and engineer orchestration architectures. It will not be positioned primarily as a framework tutorial or a collection of multi-agent demos.

## Rationale

The durable learning gap is not syntax. It is distinguishing deterministic workflows from agentic decisions and understanding state, handoffs, failures, recovery, budgets, approvals, and evidence.

## Consequences

Every lesson must explain why an agentic mechanism is introduced and when it should not be used.
