# D-005 — Teaching Method

- **Status:** Accepted
- **Date:** 2026-09-02

## Decision

Every lesson follows this sequence:

1. problem and success criteria;
2. deterministic baseline;
3. smallest justified agentic mechanism;
4. naive implementation;
5. controlled failure;
6. corrected implementation;
7. executable evidence;
8. trade-offs and when not to use the pattern.

## Consequences

A happy-path-only example is not a complete lesson.
