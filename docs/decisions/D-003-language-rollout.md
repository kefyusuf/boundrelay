# D-003 — Language Rollout

- **Status:** Accepted
- **Date:** 2026-09-02

## Decision

TypeScript and Python will be implemented together for v0.1. Go will be added after lesson structure and contracts are stable.

## Rationale

TypeScript provides strong typed contracts and a natural path to browser tooling. Python offers the broadest agent-learning ecosystem. Go is a strong production and concurrency track, but adding three implementations before the curriculum stabilizes would multiply rework.
