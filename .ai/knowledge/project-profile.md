# Project Profile

## Name

`BoundRelay` (`boundrelay`)

## Identity model

BoundRelay is the umbrella brand. The initial repository remains a single lesson-centered project. Learn, Protocol, Runtime, CLI, and Inspector are reserved future family labels, not current deliverables.

## Mission

Teach bounded, observable agent orchestration from first principles through shared scenarios, observable contracts, controlled failures, corrections, and cross-language verification.

## Canonical truth

Scenario specifications, schemas, fixtures, event contracts, and behavioral invariants.

## Language rollout

TypeScript and Python first; Go after contract stability.

## Core exclusions

No general-purpose framework, hosted platform, visual workflow builder, marketplace, autonomous self-modification, or broad production infrastructure in the initial milestone.
