# Project AI Workspace

This directory contains project-development context used by humans and AI-assisted development workflows. It is not part of the educational runtime delivered by the lessons.

- `knowledge/`: accepted project truth and durable design context;
- `governance/`: development policies, schemas, and authority boundaries;
- `delivery/`: current milestone, work units, verification plans, and evidence references;
- `runtime/`: ephemeral session artifacts and execution history that are not authoritative project truth.

No single unbounded context file is used as project memory.
